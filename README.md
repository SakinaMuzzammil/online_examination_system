# 📝 Online Examination System

A web-based Online Examination System developed using PHP, MySQL, HTML, CSS, and JavaScript. The application enables educational institutions to conduct online exams efficiently with secure authentication, role-based access, and automated result management.

---

## 🚀 Features

- Secure User Authentication
- Admin and Student Dashboards
- Exam Creation and Management
- Question Bank Management
- Timer-Based Online Exams
- Automatic Result Generation
- Performance Reports
- Profile Management
- Responsive User Interface

---

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/Online-Examination-System.git
```

2. Open the project folder.

3. Import the SQL database into MySQL.

4. Configure database credentials inside `config.php`.

5. Run the project using XAMPP or any PHP server.

6. Open

```
http://localhost/Online-Examination-System
```
